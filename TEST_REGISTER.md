## How to Use This Register in Each Session

1. **Start of session:** Read all `Open` and `In Progress` rows before starting any new work.
2. **User reports a bug:** Assign next TR-ID, fill all columns in the **Active Issues** table. Set status `Open`.
3. **Starting a fix:** Move status to `In Progress`.
4. **Fix complete:** Move the row to **Resolved Issues** table, fill `Date Fixed`, `Fix Summary`, and `Files Changed`. Set status `Fixed`.
5. **Cannot fix now:** Move to **Deferred / Won't Fix**, state the reason.
6. **SRS implicated:** Note the `SRS Ref` column and flag it — the SRS may need updating alongside the fix.
